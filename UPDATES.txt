STREAMLOCK V10 — COMPACT DEVELOPER UI, PLAYER & STORAGE VISIBILITY

PLAYER
- Reduced controls to small corner docks and a slim bottom-edge timeline.
- Clicking the video immediately hides or shows the controls.
- Automatic inactivity hiding, playback, volume, speed, quality, seeking,
  fullscreen, and external-source API behavior remain intact.
- Featured Next Video and its scroll prompt remain.
- Removed only the More Videos to Watch section.

UPLOAD AND SYNC STATUS
- Added visible preparing, uploading, syncing, success, and failure indicators
  for video files, thumbnails, commercials, links, lists, and settings.
- Added straightforward file/link validation before publishing.

DEVELOPER HUB
- Manage Video Lists now opens inside the Developer Hub as an integrated pane.
- Other tab activation remains independent and unchanged.
- Replaced the long video table with compact individually expandable cards.
- Removed all Expand all and Collapse all controls.
- Added a Supabase media storage meter with actual tracked bytes, file count,
  estimated remaining plan space, refresh, and a direct Storage dashboard link.
- The default plan allowance is 1 GiB and can be changed in supabase-config.js.
  Usage is calculated from media_files metadata, not simulated.

VIDEO LISTS
- Browse, favorites, collection videos, and Existing Collections now use small
  vertical cards in responsive grids instead of long horizontal rows.

CLOUD
- Supabase authentication, shared content, media, favorites, stats, security
  policies, and setup documentation from v9 remain included.
